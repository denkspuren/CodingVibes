# README

Als Zweitgutachter der Masterthesis von Jan Silas Jäger ("Adding Stratified Negation to a Rust-based Datalog Engine utilizing Magic Sets", Erstgutachter [Prof. Dr. Michael Elberfeld](https://www.thm.de/mni/michael-elberfeld), Kolloquium am 14. Juli 2026) habe ich mir von Claude.AI eine Datalog-Implementierung erstellen lassen, um mich in [Datalog](https://en.wikipedia.org/wiki/Datalog) einzuarbeiten und die Konzepte dazu zu verstehen. Gleichzeitig half die naive Implementierung dabei, die Beispiele aus der Thesis auf Richtigkeit zu überprüfen (sie sind alle korrekt).

Wie die Implementierung von insgesamt rund 750 LOC zeigt, beschränkt sich der konzeptuelle Kern von Datalog auf die ersten rund 300 LOC. Die Herausforderung ist, effiziente Mechanismen der Ausführung zu finden.

Das beigefügte Handbuch zu Datalog ist ebenfalls von Claude.AI auf Aufforderung geschrieben und inhaltlich nicht validiert. Als Einstieg kann es helfen -- aber es muss kritisch hinterfragend und Quellen prüfend gelesen werden.

Wer Interesse an einer forschungsorientierten Abschlussarbeit zu Datalog und der Implementierung in Rust hat, wende sich an Prof. Elberfeld.
